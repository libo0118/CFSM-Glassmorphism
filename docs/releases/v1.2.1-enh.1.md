基于 `CFSM-Glassmorphism` v1.2.0 移植三项增强特性，完整适配 CF-Server-Monitor 数据协议与设置面板：

## 新增

- **卡片三网分三行显示延迟与丢包**：底部双面板改为「延迟 / 三网」与「丢包 / 三网」，固定按联通（红）、电信（蓝）、移动（绿）三行对齐展示窗口平均数值与 20 桶分段色阶柱条；非三网节点或关闭开关时自动回落至原有单行面板。
- **顶部自定义标签与三网回程线路摘要**：自定义标签默认移至卡片顶部状态行右侧展示；顶部状态行下方支持三列等宽居中的三网线路标签（联通/电信/移动），同时支持在主题设置页「09 · 增强展示」集中配置以及从节点标签解析。
- **地球集群弧线**：贴图地球（`globe.gl`）、点阵地球（`cobe`）与平铺地图同步支持自动区域聚类连接弧线，默认以 `CN`（若存在）或最多节点区域作为枢纽，可在主题设置页切换「自动动态弧线」「常驻实线弧线」或「关闭弧线」。
